My Reflection

What I got wrong at the start: I initially thought reading a CSV file in C++ would be very difficult and require external libraries. However, using basic file streams and stringstream made it quite simple.
What I would cut: I originally planned to track the names of the students who took the bottles. I cut this feature because the guard only cares about the total bottle count, not the student identities.
Where AI helped vs wasted time: AI was very helpful in providing the quick C++ syntax for file handling. However, AI wasted my time initially by suggesting complex React.js setups, which I dropped to use a simple C++ script instead.
